# Let’s Have Fun

An experimental bench for off-the-hip edge cases: make the odd question concrete, expose its assumptions and see what unfolds.

## Experiment 01 · One neurone, many boundaries

An interactive resolution experiment built around an M1 intrinsically photosensitive retinal ganglion cell (ipRGC).

The experience begins with the sort of point-neurone abstraction used to run a whole-brain connectome on neuromorphic hardware, then restores empirically supported degrees of freedom one layer at a time: morphology, distributed membrane state, melanopsin phototransduction, intracellular signalling, cytoskeletal transport, endogenous chromophores and living tissue context.

This is not a digital twin. It is an evidence-labelled demonstration of how observer-selected resolution can make a model look computationally complete.

## Run locally

Open `index.html` directly, or serve the directory with any static HTTP server.

## Evidence policy

Every layer is labelled as one of:

- `M1 / ipRGC`: demonstrated in the anchor cell class or its intrinsic phototransduction pathway.
- `retinal neurone`: demonstrated in retinal neurones, but not jointly parameterised for this M1 cell.
- `neurone-general`: established cellular neuroscience imported into the composite.
- `frontier`: a real light-responsive intracellular mechanism whose quantitative relevance to an intact M1 ipRGC is unresolved.

The public record does not contain one simultaneous, living measurement of all these scales in one neurone. The gaps are part of the argument, not values silently filled by the interface.
